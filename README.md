# Competitive Programming Prep

This repository contains solutions and templates for various competitive programming contests and challenges.

## Folders

- **advent/**: Solutions for [Advent of Code](https://adventofcode.com/) 2023 and 2024
- **codeforces/**: Solutions for [Codeforces](https://codeforces.com/) contests
- **meta2024/**: Solutions for [Meta Hacker Cup 2024](https://www.facebook.com/codingcompetitions/hacker-cup/2024)
- **TRD/**: Templates used for ICPC 2023 Mid-Atlantic Regionals
